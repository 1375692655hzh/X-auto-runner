# 控制台设置清单（运营台 v2 需求基线）· 2026-10-23

> 权限级别：【随时调】保存即生效｜【只能紧】安全参数仅允许往严格方向调｜【提案制】改动走审批/回归预检
> ｜【只读】仅展示｜【红线】永远不做设置项（代码强制）
> 生效语义标注原则：每项标明 即时热加载 / 下次唤醒 / 需重启 / 次日生效。

## 二、红线清单（不存在设置项，代码强制）

1. unknown 绝不重发
2. state/ 账本单写者
3. 幂等键与 24h 正文查重
4. "只能动打开过的帖"
5. 熔断后必须人工恢复
6. 安全预算/间隔只能紧不能松

## 三、配套设计（与控制台一起交付）

1. **设置审计日志**：谁/何时/从哪（QQ/网页）/改了什么/生效方式——与 agent 动作账本同级
2. **生效语义标注**：每个设置项标明生效方式，避免"改了没反应"
3. 访问面：v1 SSH 隧道访问（零开发）；产品化多用户访问（账号体系+HTTPS）为后续独立工作

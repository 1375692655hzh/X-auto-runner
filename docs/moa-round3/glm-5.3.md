# X 账号运营智能体完整方案（自主决策主体版）

## 0. 本方案与五份管线答卷的根本分野

五份管线答卷的共同形态：APScheduler 定时→LangGraph 固定图→图的节点里调 LLM。LLM 是"管线里的一个函数"，决策权在图和调度器手里。本方案把拓扑反转：**一个常驻的运营体（X-Operator）持有全部微观决策权，确定性代码只做三件事——把世界呈现给它、守住它行动的后果、把它从崩溃里捞回来。**四个决策权移交：

1. **议程自主**：没有"内容管线子图""互动子图"。运营体被唤醒后自己决定这一轮做什么——刷时间线、给互关好友回帖、写一条热点评论、还是继续睡。"今日议程"是它自己维护、自己改写的工作记忆。
2. **时机自主**：没有调度器写死的发帖 slot。何时发帖由运营体自己判断（护栏内：最小间隔、活跃窗口、日预算硬顶）。调度器只负责"叫醒它"。
3. **记忆自主**：运营体通过记忆工具读写自己的长期状态。夜间由同一个身份的"睡眠态"整理记忆（借鉴 Letta sleep-time compute），这是它自己的成长，不是外部 ETL。
4. **策略自主（带版本化约束）**：每周调参由运营体自己复盘、自己提案——宏参数落盘走白名单+格子约束+版本链+可回滚。微观自主、宏观可审计。

## 1. 总体架构：一个常驻 Agent + 三圈守护

- **第一圈 唤醒层**（只叫醒不指挥）：心跳唤醒（白昼每 15-45min 随机）| 事件唤醒（新 mention/审批落定/熔断）| 日历唤醒（23:00 夜整理/周日调参/07:40 封禁自检）。
- **核心 X-Operator 认知循环**（自研薄循环，模型即主体，旗舰 GLM）：唤醒→读态势(世界快照)→审议(想干什么/为什么)→提交行动→观察结果→微反思→休眠(自己定睡眠时长)。持有：工作记忆(今日议程)|自我模型(人设+教训)|工具带(MCP)。
- **第二圈 闸门与执行器**（确定性）：预算器|风险词门禁|幂等执行→审批队列(飞书/面板)→熔断器|STOP|影子封禁自检。
- **第三圈 地基**（确定性）：SQLite 事件账本(WAL)|浏览器侧车(XActions 常驻 Chrome)|fxtwitter 只读|NSSM 看护|watchdog|备份|审计。

**三方契约**：代码负责呈现世界（每次唤醒组装《态势报告》——时间、预算余量、收件箱摘要、待审队列、昨日数据、熔断状态；组装是代码的事，保证模型看到的世界是真的）；模型负责决定行动（读完态势干什么，是旗舰模型的判断，代码不预设"接下来应该写帖"）；工具层负责守住后果（所有 X 写操作不是 agent 直接执行，而是提交为"行动提案"，经预算/风险/幂等三道闸门后由确定性执行器落地。**护栏长在工具执行器里而不是提示词里——模型无法用任何话术绕过它自己够不到的代码**）。

## 2. 决策内核：X-Operator 认知循环（方案主体）

### 2.1 循环六阶段
| 阶段 | 执行者 | 内容 |
|---|---|---|
| 1 唤醒 | 调度器 | 三类唤醒信号入队；检查 STOP 与熔断，红灯则只组装报告不进审议 |
| 2 读态势 | 代码 | 《态势报告》：作息窗、三类预算余量、未读 mention 摘要、互动候选 top-N（带画像与互关标记）、近 24h 自发帖表现、待审/已批未执行提案、夜整理"今日提示"、当前自主等级表 |
| 3 审议 | **旗舰模型** | 结构化决策：本轮意图（browse/draft_post/reply/like/investigate/rest）、理由、目标对象、要动用的记忆（自主调用记忆工具检索画像与案例） |
| 4 行动 | 模型→工具 | 读类工具直接执行；写类工具生成提案（含全文、目标、风险自评、建议执行时刻）进队列；每轮行动数 ≤3 |
| 5 微反思 | flash 档 | 行动结果一句话入情景日志；异常记入当日教训 |
| 6 休眠 | 模型自定 | 模型给出 15-90min 的下次心跳建议（调度器只钳制上下限），落库退出 |

### 2.2 运营体的自我状态（MemGPT 式 core memory blocks）
1. **今日议程块**（可自我改写）：今日已发/已回/已赞、待办（它自己列的）、今晨夜整理的选题提示、临时禁忌。崩溃恢复后从这里续住。
2. **自我模型块**（人设内化+教训）：人设卡 vN + 近期教训 top-5（"上周三那句反问被当成杠，对陌生号少用反问"）。
3. **世界观块**：x-algorithm 知识的结构化表达 + 运营纪律。这是它做判断的"行业经验"，不是外挂规则。

### 2.3 一次典型唤醒走查
10:14 心跳唤醒。态势：预算 发2/回9/赞17；互关好友新帖谈开源推理框架中文文档缺位（互关、话题命中）；昨晚帖 24h likes41/replies12 高于近 14 天中位；自主等级：Safe 回复 L3（自动）、发帖 L1（人工审）。
运营体审议：①先回互关（reply 权重×4 且有可接的具体点）；调记忆工具拉历史互动 3 条，选 Interesting 档写 62 字，自评低风险，L3 直接放行进执行器；②今天第二次发帖预算留给晚间——夜整理提示的"端侧小模型延迟实测"选题还没写，决定 20:30 左右再写，写入议程块；③点赞一条真读过的 GPU 长文。自定 38 分钟后唤醒。
执行器侧：回复过风险词门禁→humanize 判分 8.4→幂等 action_id 落地→侧车按拟人节奏（阅读 22s→打字 71s）发出→画像更新。晚间发帖走提案→飞书卡片→人批→执行，全程不阻塞等待。
——这个走查里没有任何"管线节点"在指挥它：调度器只叫醒，闸门只验货。

### 2.4 模型分层与 token 纪律
审议（主体）旗舰，白昼约 25-40 次唤醒，每次输入 2-4k/输出 ≤1k；门禁判分/微反思/蒸馏 flash ≤60；夜整理/周调参旗舰长上下文各 1。日约 15 万输入/4 万输出。**态势报告由代码装配而非让模型自己翻数据库——给它结论性的世界，不给它原始的账本。**

## 3. 记忆体系：复用你现有的记忆系统

MemoryPort 契约（get_profile/upsert_profile/log_episode/query_episodes/search_casebook/add_case/read_block/write_block）。若你的系统可 API 化：包成 MCP 工具直插工具带，SQLite 默认实现作退路。
- **夜整理**（每晚 23:00，同一身份、只读+低权模式）：蒸馏当日情景为画像增量与案例、改写三块核心记忆、产出《明日提示》、起草周调参提案。只写记忆与提案，不碰 X、不改宏参数。
- **记忆投毒防线**：所有由外部输入（mention/时间线文本）推导的画像写入只能走 log_episode，由夜整理在隔离上下文二次提炼后才进 profile——运行态循环不直接根据陌生人的话改任何人的画像。

## 4. 工具带：MCP 作为统一工具协议
X 读（XActions MCP）/ X 写（提案式，本项目包装）/ 拟人原语（侧车自写 human_type/dwell/scroll——**M0 首日用 list_tools() 实测裁决，"152+"存疑按 12 个预期**）/ 指标（fxtwitter 包装）/ 记忆（MemoryPort→MCP）/ 审批 / 研究（定向只读，白名单域名，防注入）。工具执行器内嵌三道闸（预算原子扣减、风险词、幂等 action_id），闸门在代码层，模型不可协商。

## 5. 外置审批与幂等执行（根除 interrupt 重跑问题）
**提案-审批-执行三分离**：运营体提交行动提案（action_proposals 表）后立即继续/休眠，进程内零等待；审批是数据库行状态不是进程内中断。闸门自动初筛→按自主等级决定自动放行或飞书等人；人审卡片（通过/改后发/驳回，改后重过门禁）；执行器是唯一持有 X 写权限的确定性组件（幂等三查：状态→远端回读对账→近 20 条正文哈希，grok 的 uncertain 对账程序）。崩溃恢复=账本事件溯源重放，未决提案不重发。**一切状态在库里，进程只是状态的临时载体。**

## 6. 自主性分级：L0-L4 授权矩阵
| 等级 | 语义 |
|---|---|
| L0 | 只能浏览与提案，一切写需人批 |
| L1 | 提案+闸门+人批后执行 |
| L2 | 低危动作自动（like 已读帖、Safe 回复），抽审 10% |
| L3 | 该类动作常态自动，异常升级人审 |
| L4 | 含敏感类别自动+参数提案自动生效（最后才给） |

爬坡：点赞 L2 起；Safe 回复 L1→（连续 100 条通过率 ≥98% 且门禁首轮 ≥90%）→L2→再两周零事故→L3；Bold L0→warm-up 毕业+两周期无负面→L2 封顶；原创 L1→（连续 30 篇批准率 ≥95% 且自检全绿）→L2（保留每日首篇人审）→L3 封顶；关注/删帖/私信 L0 永远人批；宏参数 L1→（两真实数据周无回滚+夹具回滚演练通过）→L4。**收权即时且门槛高**：影子封禁 RED/负向信号激增/检测到注入尝试/连续 2 次幻觉得人纠正→对应类别立即降回 L1 或 L0。放权慢、收权快。

## 7. 框架选型结论
| 框架 | 定位 | 理由 |
|---|---|---|
| **自研薄循环+SQLite 事件账本**（主推运行时本体） | 决策内核 | 循环本体约 200-300 行；事件溯源天然给断点续跑/迁移/审计；不与用户记忆系统争夺所有权；无 interrupt 重跑类框架陷阱 |
| **MCP** | 工具协议 | XActions 原生讲 MCP；记忆/指标/审批/拟人原语统一包装——本案最大的"框架红利" |
| LangGraph 1.x | 备选脊柱 | 图优先心智会把人拉回管线思维；夜整理/周调参这类固定流程将来可落成图 |
| Letta（MemGPT） | 思想供应商 | core memory block、sleep-time compute、自编辑记忆；其记忆系统与用户既有系统重叠冲突，取思想不用平台 |
| OpenClaw | 架构参照物 | 证明"常驻个人 agent+网关+心跳"形态可长期跑；CVE-2026-25253 提醒对公网暴露的个人 agent 网关是高危面——面板只绑 127.0.0.1 |
| MS Agent Framework 1.0 | 不采用 | 企业多代理编排口味；AutoGen 已维护模式 |
| Pydantic AI / OpenAI Agents SDK | 可选简化件 | 连 300 行循环都不想维护时用 |

**结论组合**：Python 3.11+/自研循环/MCP 工具带/APScheduler（只做唤醒）/SQLite WAL/FastAPI 面板/Node 侧车（XActions+自写拟人原语）/智谱 GLM 双档。**这个系统要跑一年，框架越少，一年后越好修。**

## 8. 安全与风控（五卷精华+两项本卷补强）
- 预算：基数取 **3/12/20**（保证 +30% 抖动后永不破 4/15/30 硬顶）；硬护栏：帖间隔 ≥2.5h、活跃窗 08-23、每小时写 ≤4、相邻动作 25-90min。**发帖具体时刻由运营体自选（时机自主），护栏只画边界。**
- Warm-up 十四天表+毕业四条件（grok 版直接采用）。
- 熔断矩阵+STOP（删除不自动恢复，面板二次确认）；凭据 DPAPI+侧车专用 profile+日志打码+owner_host 心跳锁。
- 四维自检：①②走 fxtwitter 免账号通道；③④需外部视角（twitterapi.io 只读，无则记 untestable 用代理指标 soft 判定）；GREEN/YELLOW（预算减半停 Bold）/RED（48h 只读+7 天内新参数版本自动回滚）。
- 降级链：XActions→熔断等人→twitterapi.io 永不给写→官方 API 仅面板武装后保命。**failover 只救会话不救指纹。**
- **提示注入防御（本卷新增，五卷共同盲区）**：指令层级（系统>态势>工具结果>外部内容，外部文本包显式数据标记）；上下文相关工具裁剪（外部内容密集轮工具带收窄为只读+提案）；URL 纪律（永不自动跟随，研究白名单域名）；注入检测器（flash 扫"指令性内容"，命中降级只读不回并计数，激增触发收权）；记忆写路径投毒防线隔离。

## 9. 内容与互动：世界观与文风
- 算法知识进"世界观块"（知识层）+ 少数降格为硬护栏（代码层）：试水位→"每帖开局都有试水机会，前两小时决定命运，发出后 30 分钟内可自回补一条背景"；互关×4→"互关好友的原创帖是最贵的不动产，优先回快回真回"（候选排序互关置顶）；ShareViaCopyLink 20→"可争论的观点、开放问题、值得存档的干货是杠杆"；负向→"宁可无聊不可招恨，被杠只回一次或无视"；连发衰减→硬护栏 2.5h；48h→回收采样终点。
- humanizer-zh 双层（规则引擎硬门禁+flash 判分）；人设卡 vN 版本化，**没有人设卡时拒绝生成**。
- 回复三档+防骚扰预算（同人 24h≤1 出向、7 天≤3、单帖一回、对方回了才二回）全盘吸收 grok。

## 10. 数据回收与自优化（agent 自己的成长）
fxtwitter 四点快照（1/6/24/48h）+粉丝每小时；主 KPI=周内满 48h 帖 eng 中位数；护栏列 NEG 负向代理（掉粉≥1%/日、自有帖 404、回复被折叠、敌意占比）。夜整理每日；周调参：运营体自己在白名单格子内提案 ≤3 项带 hypothesis，版本全量快照+parent 链，连续两周期低于父版 15% 自动回滚（先夹具演练）。**对 grok"LLM 不得提议参数"持保留意见：格子管住取值域，不该连提议权也收走——agent 提案+格子约束+版本审批/自动回滚，安全由格子与回滚兜底，不由剥夺判断力兜底。**

## 11. 部署（吸收五卷收敛为本案拓扑）
Windows：xar-core（Python：唤醒器+认知循环+闸门执行器+记忆+面板API）+ xar-sidecar（Node：XActions MCP+自写拟人原语+常驻 Chrome 专用 profile）+ xar-watchdog 计划任务（心跳>3min→nssm restart+飞书）。面板只绑 127.0.0.1（OpenClaw CVE 教训），远程 SSH 隧道/Tailscale。每日 04:00 VACUUM INTO 备份保留 14 份。
迁 VPS：搬家单位=文件；DPAPI 密文 cookie 重放；headless=new 遇登录墙转 xvfb；迁后 3 天半预算观察；本机与 VPS 永不同时运行。
